## Project Description: 
This project is a web application that allows users to dynamically create and manipulate a grid of cells using JavaScript, HTML, and CSS. The project demonstrates the practical implementation of DOM manipulation and event handling by enabling users to perform actions such as adding/removing rows and columns, changing cell colors, and clearing the grid.
